# UX Interaction Inventory

## Gestures

| Interaction | Surface | Platforms |
|-------------|---------|-----------|
| Tap open chat | Chat list row | All |
| Long-press context | Chat row / message | Mobile |
| Right-click context | Chat row / message | Desktop/Web |
| Swipe archive | Chat row | Mobile |
| Swipe reply | Message | Mobile |
| Pinch zoom | Media viewer | Mobile |
| Drag-drop files | Conversation | Desktop/Web |
| Hold-to-record voice | Composer mic | All |
| Slide left cancel voice | Recording | All |
| Slide up lock voice | Recording | All |
| Pull load older | Message list | All |
| Double-click zoom | Media | Desktop |
| Swipe down close viewer | Media | Mobile |

## Keyboard (Desktop/Web)

| Shortcut | Action |
|----------|--------|
| Ctrl/Cmd+K or Ctrl+F | Search / command |
| Ctrl+N | New message |
| Ctrl+, | Settings |
| Alt+↑/↓ | Prev/next chat |
| Enter | Send |
| Shift+Enter | Newline |
| Esc | Cancel modes / close |
| Ctrl+E / ↑ empty | Edit last |
| Arrow keys | List/search nav |
| Space | Play voice/media |

## Menus

- Chat list context (pin/mute/archive/read/folder/clear/delete)

- Attach menu (photo/file/poll/location/contact)
- Compose (+) new chat/group/channel
- Avatar/profile menus
- Media viewer overflow
